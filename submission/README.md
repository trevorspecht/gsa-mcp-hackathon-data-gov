# Submission

- `Data.gov-Research-Hackathon.pptx`: 12-slide deck following the organizer sample.
- `Data.gov-Research-Evaluation.docx`: evaluation document in the organizer
  template's section structure.
- `pdf/`: PDF copies rendered with LibreOffice.
- `../eval/results/EVALUATION-SUMMARY.pdf`: visual summary of every evaluation run.
- `screens/`: screenshots from the hosted private research App (Nov 23).

Rebuild with `uv run python scripts/build_submission.py`; see
[docs/DEMO.md](../docs/DEMO.md). The organizer templates are kept outside the repository.
